# Journal

Short notes on *how* the work went, not *what* was built (that lives in
`openspec/`). This project is an experiment in AI-assisted development; these
notes are its lab book and the raw material for blog posts.

One file per working session or per OpenSpec change:
`YYYY-MM-DD-<change-name>.md`. Keep it to a few lines:

```markdown
# YYYY-MM-DD: <change-name>

**Went well:**
**Had to step in:**
**Surprise:**
**Effort:** time, review rounds
**Blog idea:**
```
