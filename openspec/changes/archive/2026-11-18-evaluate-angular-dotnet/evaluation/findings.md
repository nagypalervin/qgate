# Judged sample

The sample of design D3: every Error, and 30 Warnings per repository
drawn with `random.Random(20261117)` (`sample.py`); `jasontaylordev/CleanArchitecture`
had one finding in all. Each finding is classed (`judgements.tsv`,
merged by `judge.py`):

- **useful:** a reviewer would act on it, or want to know;
- **defensible:** correct under the rule, though a reviewer might let it
  pass;
- **noise:** wrong, or about code nobody reviews.

Every class was decided on the pull request's diff. The duplication
findings were checked with `dupcheck.py` (does the block's text occur in
the base, and how often in one file) and `dupedit.py` (how many of the
block's and its target's lines the pull request changed).

## Patterns behind the noise

- **P1, a split file.** A pull request splits one large file into
  several (`bitwarden/server` PRs 8854, 8856 and 8859, 114 of the
  repository's 181 duplication Warnings). Repetition inside the old
  file was not duplication under the rule ("copies across files only");
  in the new files it is. The code only moved.
- **P2, an edited copy.** A pull request makes the same small edit in
  blocks that were already copies (`bitwarden/clients` PR 24403 adds one
  constructor argument in 15 importer specs). One changed line in each
  block makes the whole block new.
- **Moved out of a deleted file** (SV10): the README says such code is
  not reported, but it was, from the split of PR 8854.
- **A function moved to another class or file** (SV19, and SV6's
  parameter change): its name changes, so it counts as a new function.
  For SV6 the verdict still holds (14 -> 25 as an increase).
- **An inlined function** (CL11): removing a feature flag moved the body
  of `decryptManyV2` into `decryptMany` and deleted the V1 path. The
  method's complexity rose by 8, an Error, while the pull request only
  removed code.

## Spot-check

`spotcheck.py` drew SV3, SV18, SV25, SV27, SV29, CL2, CL7, CL8, CL23 and
CL37. Each was shown to Ervin with its pull request, location, class and
reason. On 2026-11-17 he agreed with all 10, so the sample stands as
judged (D3 asks for a second round only above 2 disagreements).
