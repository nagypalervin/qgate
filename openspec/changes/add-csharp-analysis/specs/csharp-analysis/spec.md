# Spec Delta

## Purpose

C# analysis defines how qgate reads C# source: which files it reads,
which units it measures and how it names them, what counts as a decision
point, and which tokens it compares to find copies.

## ADDED Requirements

### Requirement: C# files

A file whose name ends in `.cs` SHALL be read as C#. A UTF-8 byte order
mark at its start SHALL be ignored.

#### Scenario: A file with a byte order mark

- **GIVEN** `src/Cart.cs` starts with a UTF-8 byte order mark and holds a method with one `if`
- **WHEN** the file is analyzed
- **THEN** the method has complexity 2 and no `input/unparsable` finding is reported

### Requirement: Generated C# files are skipped

In revision mode, a C# file SHALL be skipped as if it were not
supported when its name ends in `.designer.cs`, `.generated.cs`, `.g.cs`
or `.g.i.cs`, or starts with `TemporaryGeneratedFile_`, ignoring case,
or when a comment before its first code contains `<auto-generated` or
`<autogenerated`. A skipped file takes no part in duplication either.

#### Scenario: An EF Core migration

- **GIVEN** the change adds `Migrations/20261113_AddOrders.Designer.cs` and `Migrations/AppDbContextModelSnapshot.cs`, whose first line is `// <auto-generated />`, both repeating a long model built in an older migration
- **WHEN** the user runs `qgate check --base main`
- **THEN** no finding is reported for either file

#### Scenario: A file by name

- **GIVEN** the change adds `Forms/Main.Designer.cs` with a method of complexity 30
- **WHEN** the user runs `qgate check --base main`
- **THEN** no finding is reported for it

### Requirement: C# function units

Every method, constructor, finalizer, operator, conversion operator and
local function with a body or an expression body SHALL be a function
unit, and so SHALL every accessor of a property, indexer or event with
one, and an expression-bodied property or indexer. Declarations without
a body (abstract, interface, `extern`, `partial`) SHALL NOT be units.

#### Scenario: The members of a class

- **WHEN** a class has a constructor, a method, a property with a `get` and a `set` body, an expression-bodied property, an operator and a local function inside the method
- **THEN** each of them is measured separately: seven units

#### Scenario: Declarations without a body

- **WHEN** a file holds an interface with two methods and an abstract class with an abstract method
- **THEN** no function unit is found

### Requirement: C# lambdas count towards their named ancestor

A lambda or anonymous method SHALL NOT be a unit of its own; its
decision points SHALL count towards the nearest enclosing unit. Code
outside units, such as field initializers and top-level statements,
SHALL NOT be measured; a local function among top-level statements SHALL
be a unit.

#### Scenario: A LINQ query in a method

- **GIVEN** `int Paid(List<Order> o) => o.Count(x => x.Paid && !x.Void);`
- **WHEN** the file is analyzed
- **THEN** the only unit is `Paid(List<Order>)` with complexity 2

#### Scenario: Top-level statements

- **GIVEN** a `Program.cs` whose top-level statements hold an `if` and the local function `int Twice(int x) => x > 0 ? 2 * x : 0;`
- **WHEN** the file is analyzed
- **THEN** the only unit is `Twice(int)` with complexity 2

### Requirement: C# qualified names

A unit's name SHALL be the names of its enclosing types and units,
joined by `.`, followed by its own name; namespaces SHALL be left out.
A method, constructor, finalizer, operator or local function SHALL
carry its type parameters and its parameter list in its own name. An
accessor SHALL be named by its property, indexer or event followed by
`.get`, `.set`, `.init`, `.add` or `.remove`.

#### Scenario: Names in a class

- **GIVEN** `namespace Shop; class Cart { Cart(IClock c) {} decimal Total(int d) => 0; string Owner { get => ""; init {} } int this[int i] => 0; }`
- **WHEN** the file is analyzed
- **THEN** the units are named `Cart.Cart(IClock)`, `Cart.Total(int)`, `Cart.Owner.get`, `Cart.Owner.init` and `Cart.this[int].get`

#### Scenario: Nested types, local functions and operators

- **GIVEN** `class Outer { class Inner { T Map<T>(ref T x, params int[] ys) { int Add(int a, int b) => a + b; return x; } public static Inner operator +(Inner a, Inner b) => a; ~Inner() {} } }`
- **WHEN** the file is analyzed
- **THEN** the units are named `Outer.Inner.Map<T>(ref T, params int[])`, `Outer.Inner.Map<T>(ref T, params int[]).Add(int, int)`, `Outer.Inner.operator +(Inner, Inner)` and `Outer.Inner.~Inner()`

### Requirement: C# parameter lists in names

A parameter list SHALL hold each parameter's modifiers and type as
written, without whitespace except one space between two words,
joined by `, ` and enclosed in parentheses, or in brackets after `this`
for an indexer. Names and default values SHALL be left out.

#### Scenario: Overloads

- **GIVEN** a class `Cart` with `Total(int discount = 0)`, `Total(string code)` and `Total(Dictionary<string, int> m, out int n)`
- **WHEN** the file is analyzed
- **THEN** the units are named `Cart.Total(int)`, `Cart.Total(string)` and `Cart.Total(Dictionary<string,int>, out int)`

#### Scenario: An overload added above

- **GIVEN** the before file has `Cart.Total(int)` with complexity 4, and the after file adds `Total(string)` above it, unchanged otherwise
- **WHEN** the two files are compared
- **THEN** `Cart.Total(int)` is matched with complexity 4 in both, and no finding is reported for it

### Requirement: C# decision points

The system SHALL count one decision point for each: `if`; `for`,
`foreach`, `while` and `do` loop; `case` label of a switch statement;
switch expression arm whose pattern is not the discard `_`; `when`
clause; `catch` clause; conditional expression `? :`; operator `&&`,
`||` and `??`; assignment `??=`; conditional access `?.` and `?[]`; and
pattern combinator `and` and `or`.

#### Scenario: Loops and switch

- **WHEN** a method contains one `foreach` loop, one `do` loop and a `switch` statement with two `case` labels and a `default`
- **THEN** its complexity is 5

#### Scenario: Switch expression and patterns

- **WHEN** a method is `int F(int d) => d switch { 0 => 1, > 0 and < 50 => 2, _ => 3 };`
- **THEN** its complexity is 4 (two arms and one `and`; the `_` arm does not count)

#### Scenario: Errors and null handling

- **WHEN** a method contains a `try` with a `catch` that has a `when` filter and a `finally`, one `?.` and one `??`
- **THEN** its complexity is 5

#### Scenario: Optional parameters do not count

- **WHEN** a method is `int F(int x = 1) { return x; }`
- **THEN** its complexity is 1

### Requirement: C# normalized tokens

In C#, these rules SHALL replace the TypeScript ones of
`duplication-analysis`. Identifiers SHALL become the identifier placeholder, except the name
after `.`, `?.` or `->`, which keeps its text. Each string, character
and number literal, and each text part of an interpolated or raw
string, SHALL become the literal placeholder. Keywords, including
predefined types, `true`, `false` and `null`, operators and other
punctuation SHALL keep their text.

#### Scenario: Renamed copy

- **GIVEN** `string Fmt(DateTime d) { var y = d.Year; return $"{y}-"; }` and `string FormatOrderDate(DateTime when) { var year = when.Year; return $"{year}/"; }`
- **THEN** both have the same normalized tokens

#### Scenario: Different members

- **GIVEN** two methods that differ only in reading `.Year` and `.Month`
- **THEN** their normalized tokens differ

### Requirement: C# code without tokens

`using` directives, the name of a namespace declaration, preprocessor
directives, comments and semicolons SHALL produce no tokens.

#### Scenario: Usings and namespaces are not compared

- **GIVEN** two files that share only a long list of `using` directives and a file-scoped namespace declaration
- **THEN** no tokens are compared for them and no duplicate is found

### Requirement: Conditional compilation

Preprocessor directives SHALL NOT be evaluated: the code of every
branch of an `#if` SHALL be read as if the directives were absent. A
file that is not valid C# read this way SHALL be unparsable.

#### Scenario: A guarded statement

- **WHEN** a method contains `#if DEBUG`, one `if` statement and `#endif`
- **THEN** its complexity is 2

#### Scenario: Branches that open blocks

- **GIVEN** the head version of `src/Startup.cs` opens an `if` block in both branches of an `#if`/`#else` and closes it once after `#endif`
- **WHEN** the user runs `qgate check --base main`
- **THEN** the only finding for `src/Startup.cs` is `input/unparsable`
